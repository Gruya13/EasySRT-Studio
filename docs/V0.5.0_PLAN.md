## Workstream 1 — Remove Duplicate Native Windows Titlebar (`decorations: false`)

### User Report & Root Cause
- **User Report:** On Windows 10/11, users see **two titlebars** with duplicate Minimize / Maximize / Close (`×`) window controls — the native Windows OS titlebar stacked on top of EasySRT Studio's custom `TopBar`.
- **Root Cause:**
  1. EasySRT Studio renders its own custom studio titlebar (`<header id="titlebar" data-tauri-drag-region>` in [`src/components/TopBar.tsx`](../src/components/TopBar.tsx)) and already configures window control permissions in [`src-tauri/capabilities/default.json`](../src/tauri/capabilities/default.json) (`allow-minimize`, `allow-toggle-maximize`, `allow-maximize`, `allow-unmaximize`, `allow-close`, `allow-start-dragging`).
  2. However, [`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json) (`app.windows[0]`) omits `"decorations": false`, so Tauri defaults to `"decorations": true`.
  3. On tiling Wayland compositors (Hyprland on Linux), OS decorations are suppressed automatically, masking the issue; on **Windows 10/11**, Win32 renders the native `WS_CAPTION` titlebar above the webview.

### Planned Changes
1. **Disable Native OS Decorations (`src-tauri/tauri.conf.json`)**:
   - Add `"decorations": false` (and `"shadow": true` if supported cleanly on Windows 11 rounded corners/drop-shadow) to `app.windows[0]` in [`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json).
2. **Titlebar Drag & Double-Click Maximize Ergonomics (`src/components/TopBar.tsx`)**:
   - Ensure `data-tauri-drag-region` covers all non-interactive areas of `#titlebar` (`.titlebar-left`, `.titlebar-center`, `.titlebar-right` containers, excluding `<button>` elements) so dragging the window when unmaximized and double-clicking the bar to toggle maximize/restore feel native on Windows.
   - Sync React `maximized` state cleanly via Tauri window resize/maximize listeners (`getCurrentWindow().onResized(...)` + `isMaximized()`) so the Restore/Maximize icon always reflects OS window state (e.g., after `Win + Up` / `Win + Down` shortcuts).
3. **Windows Taskbar Work-Area & Unmaximized Resize Guard**:
   - Verify on Windows 10/11 that `"decorations": false` + `"maximized": true` respects the monitor work area (does **not** cover the Windows bottom taskbar; if startup `"maximized": true` on frameless Win32 covers the taskbar on certain DPI configurations, initialize unmaximized in config and call `window.maximize()` inside `.setup(...)` in `src-tauri/src/lib.rs`).
   - Confirm edge/corner window resizing works smoothly when unmaximized (`resizable: true`, adding `core:window:allow-start-resize-dragging` border grips if needed on Linux floating WMs / Windows).

### Verification Checklist
- [ ] Windows 10/11 build shows **only** EasySRT Studio's custom `TopBar` (native Windows titlebar is completely gone).
- [ ] Maximized window leaves the Windows bottom taskbar visible and accessible.
- [ ] Unmaximizing, dragging via `#titlebar`, double-clicking `#titlebar` to maximize, `Win + Arrow` snapping, and Minimize / Maximize / Close buttons all work as expected.

## Workstream 2 — Privacy-First Telemetry & Automated AI-vs-Human Learning Engine

**Full Architecture & Legal Specification:** [`docs/TELEMETRY_AND_LEARNING_PLAN.md`](TELEMETRY_AND_LEARNING_PLAN.md)

### Summary of Planned Changes
1. **GDPR & Serbian ZZPL Explicit Opt-In Consent (`SetupWizard.tsx`, `SettingsPanel.tsx`, `PRIVACY.md`)**:
   - Replace silent default-on crash reporting with three explicit, revocable toggles (`autoSendCrashReports`, `shareAnonymousUsageMetrics`, `shareAnonymizedTranslationEdits`), a live **"View Exact JSON Sample"** inspector, `DO_NOT_TRACK=1` / `EASYSRT_TELEMETRY_URL=off` kill-switches, and zero-IP / zero-`device_id` handling at the Cloudflare Worker edge.
2. **Zero-Click Export-Triggered Diff Engine (`src-tauri/src/pipeline/telemetry_diff.rs`)**:
   - Snapshot `SubtitleProject.ai_baseline_cues` upon pipeline completion and compare `AI Baseline ↔ Final Cues` locally in `< 5 ms` when the user clicks **Export** (sent asynchronously in the background).
   - **Level 1 (Performance)**: Hardware/VRAM tier, Whisper/LLM backends, real-world RTF, OOM fallbacks, and batch subdivision retries.
   - **Level 2A (Structural & Grammatical Classifiers, Zero Text)**: Edit rate KPI, CPS before/after, split/merge context, average timeline start/end trim deltas (`ms`), and local Serbian fix counters (enclitic reordering, redundant possessives → `svoj`, `"od strane"` passives, conjunction-comma fixes, missed fillers, inflection suffix fixes, boundary orphan shifts).
   - **Level 2B (`k >= 5` K-Anonymous Lexical Diffs)**: Extracts isolated `1–3` word lowercase edits strictly free of uppercase proper nouns, digits, symbols, and glossary entries; stored in **Cloudflare D1** on `easysrt-telemetry.ig-systems.rs` and surfaced to maintainers **only** once `>= 5` independent monthly cohorts make the identical correction (with 30-day Cron TTL purge of rare rows).
   - **Level 3 (Optional AI Training Opt-In)**: Separately gated toggle that sends `[NAME]`/`[NUM]`-sanitized `(source, initialAi, finalHuman)` modified cue pairs at Export, with a 1-click *"Skip for this export"* pill in `ExportModal.tsx`.
3. **Maintainer Digest CLI (`scripts/telemetry-digest.mjs`)**:
   - One-command report (`npm run telemetry:digest`) summarizing GPU RTFs, edit-rate trends across releases, top K-anonymous lexical fixes, and donated training pairs.

## Workstream 3 — Serbian Linguistic & Translation Quality Engine

**Full Linguistic Specification:** [`docs/LINGUISTIC_TRANSLATION_PLAN.md`](LINGUISTIC_TRANSLATION_PLAN.md)

### Summary of Planned Changes
- Decouple `AddressForm` (`Auto` / `PoliteVi` / `InformalTi`) from `TranslationStyle` (`Natural` vs. `Formal`) so broadcast/press interviews naturally combine polite `Vi` with contemporary spoken Ekavian syntax (`da` + present).
- De-overfit `translator.rs` examples into domain-agnostic linguistic rules, strengthen anti-calque / anti-pleonasm guardrails, enforce Serbian conjunction-comma hygiene, and feed domain/register hints from `probe.rs`.
